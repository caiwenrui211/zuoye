# 한중 한국어 기초 상식 퀴즈 게임 / 韩中韩语基础常识问答游戏

한국어 기초 상식을 재미있게 복습하고, 한국어 학습자가 한국어와 중국어 단어를 함께 확인할 수 있도록 제작한 단일 HTML 기반 퀴즈 웹 애플리케이션입니다.  
这是一个以趣味方式复习韩语基础常识、方便韩语学习者同时对照中韩双语词汇的单个 HTML 问答网页作品。无需安装、无需后端服务器，打开浏览器即可直接运行。

---

## 주요 기능 / 主要功能

- **시작 화면 / 开始界面**：작품 소개, 문항 수(총 6문항), 난이도(입문~초급) 안내  
  展示作品介绍、题目数量（共 6 题）与难度说明（入门至初级）。
- **객관식 문항 / 选择题**：총 6개 문항, 각 4지선다 보기, 모든 문항·보기 한중 병기  
  共 6 道题，每题 4 个选项，题目与选项均采用韩中双语并列显示。
- **즉시 피드백 / 即时反馈**：보기 선택 즉시 `정답 / 오답`(`正确 / 错误`) 표시 및 한중 이중언어 해설·핵심 어휘 태그 제공  
  选择答案后立即显示“正确 / 错误”，并给出双语解析及核心词汇对照。
- **점수 집계 / 计分**：풀이 중 실시간 점수 및 진행률 표시, 종료 후 최종 점수·정오답 요약·격려 평어 제공  
  答题过程中实时显示当前得分与进度，结束后展示最终得分、各题正误回顾与鼓励评语。
- **다시 시작 / 重新开始**：원클릭으로 점수와 상태를 초기화하여 처음부터 다시 풀이 가능  
  支持一键重置分数与答题状态，重新开始答题。
- **반응형 레이아웃 / 响应式布局**：모바일과 PC 브라우저 환경 모두에서 깔끔하게 표시  
  适配手机与电脑端浏览器屏幕，显示清晰自然。

## 실행 방법 / 运行方法

이 프로젝트는 단일 HTML 파일로 제작되었으며, 별도의 서버나 빌드 과정이 필요 없습니다.  
本项目为单个 HTML 文件，无需服务器或构建步骤。

### 방법 1. 파일 직접 열기 / 直接打开文件

1. 저장소를 클론하거나 파일을 다운로드합니다. / 克隆仓库或下载文件。
2. `quiz-game.html` 파일을 더블 클릭하여 브라우저로 엽니다. / 双击 `quiz-game.html`，用浏览器打开即可。

### 방법 2. 로컬 웹 서버 사용 (선택 사항) / 使用本地服务器（可选）

```bash
# 프로젝트 폴더에서 / 在项目目录下
python -m http.server 8000

# 브라우저에서 접속 / 浏览器访问
# http://localhost:8000/quiz-game.html
```
